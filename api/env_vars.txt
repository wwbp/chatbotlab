# Every environment variable the deployed application reads, one per line.
# chatbot/tests/test_env_vars.py keeps this list in step with the code.
# infra/terraform/tests/env_parity.tftest.hcl checks that Terraform sets each
# one for production, except the names marked "unset:", with the reason.
ALLOWED_HOSTS
ANTHROPIC_API_KEY              unset: a secret; read from Secrets Manager (APP_SECRET_ID), never an EB setting
APP_SECRET_ID
AWS_ACCESS_KEY_ID              unset: the instance role gives AWS access; static keys would override it
AWS_BUCKET_NAME
AWS_REGION
AWS_SECRET_ACCESS_KEY          unset: as AWS_ACCESS_KEY_ID
BACKEND_ENVIRONMENT
CHATBOT_AVATAR_PROMPT          unset: fallback for bots without their own avatar prompt; live production does not set it
CHATBOT_CONTROL_IMAGE          unset: image for the "control" avatar condition; live production does not set it, a study that uses it sets it
CONN_MAX_AGE
CORS_ALLOWED_ORIGINS
CSRF_TRUSTED_ORIGINS
DATABASE_HOST
DATABASE_NAME
DATABASE_PASSWORD              unset: from the RDS-managed secret (DATABASE_SECRET_ID), never an EB setting
DATABASE_PORT
DATABASE_SECRET_ID
DATABASE_USER                  unset: as DATABASE_PASSWORD; the secret holds the username
DEBUG
DEFAULT_FROM_EMAIL
DJANGO_SETTINGS_MODULE         unset: manage.py, asgi.py and wsgi.py set it
DJANGO_SUPERUSER_EMAIL         unset: production never creates accounts at boot; the copied DB has the real admins; use a one-off manage.py createsuperuser if ever needed (the test stack sets all three)
DJANGO_SUPERUSER_PASSWORD      unset: as DJANGO_SUPERUSER_EMAIL
DJANGO_SUPERUSER_USERNAME      unset: as DJANGO_SUPERUSER_EMAIL
EMAIL_BACKEND
FRONTEND_URL                   unset: CORS_ALLOWED_ORIGINS and CSRF_TRUSTED_ORIGINS already name the front end
GUNICORN_WORKERS
MOCK_LLM
MOCK_LLM_P50_MS                unset: read only when MOCK_LLM is true, never in production
MOCK_MODERATION_P50_MS         unset: as MOCK_LLM_P50_MS
MODERATION_VALUES_FOR_BLOCKED  unset: the thresholds in settings.py are the reviewed ones
OPENAI_API_KEY                 unset: a secret; read from Secrets Manager (APP_SECRET_ID), never an EB setting
REDIS_URL
SECRET_KEY                     unset: a secret; read from Secrets Manager (APP_SECRET_ID), never an EB setting
SITE_URL
SURVEY_INGEST_TOKEN            unset: a secret; read from Secrets Manager (APP_SECRET_ID), never an EB setting
